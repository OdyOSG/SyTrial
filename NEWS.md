# SyTrial 0.1.0

## Initial Release

### Features

- Index date imputation for control cohorts (risk set sampling, calendar matching, sequential trial emulation)
- High-dimensional covariate extraction using HADES FeatureExtraction
- Large-scale propensity score modeling with Cyclops
- TMLE implementation with Super Learner integration
- G-computation for causal inference
- Overlap weighting and IPTW
- Comprehensive diagnostic tools (Love plots, Kaplan-Meier curves)
- Full integration with OHDSI HADES framework

### Documentation

- Complete function documentation
- Tutorial vignette with case study
- README with quick start guide

### Testing

- Unit tests for core functions
- Integration tests with mock OMOP CDM data
